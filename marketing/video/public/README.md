# Music slot

Drop your Apple-keynote-style track here as **`music.mp3`** — Remotion picks it up automatically.

Any 60-second (or longer) clip works: everything past 60s is trimmed. If no
file is present, both videos render silent.

## Where to find the right track

- **Artlist** — search "corporate uplifting piano", "cinematic tech minimal"
- **Musicbed** — "Apple keynote", "product launch"
- **Epidemic Sound** — "minimal tech piano", "sleek innovation"
- **PremiumBeat** — "modern corporate calm"

Reference vibe: Apple product-launch pre-roll — soft piano/synth, gradual
build, one climax around 40-50s, breathes at the end for the CTA.

## Volume

Baseline is 0.35 — enough to feel present without stepping on captions or a
future voice-over. Change in `src/music.ts` if you want it louder or softer.
